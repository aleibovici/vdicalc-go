About VDI Calculator

The VDI Calculator sizes Virtual Desktop Infrastructure deployments for host, storage, virtualization, and Azure instance needs.

Defaults target Windows 11 single-session desktops on modern dual-socket hosts, with Azure recommendations on the Ds_v5 / NVads_A10_v5 families.

Baselines draw from Microsoft AVD session-host sizing, Omnissa/Dell Horizon Windows 11 guidance, and published density studies. Always validate with a pilot.

Originally created by André Leibovici at myvirtualcloud.net. Runs entirely in your browser.
